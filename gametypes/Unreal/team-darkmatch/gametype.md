A Team Game version of DarkMatch.

Team DarkMatch is a Team Game version of DarkMatch and uses DarkMatch (DK) maps.

## Play Information

- Game: Unreal
- Game Type: Team DarkMatch
- Multiplayer: Yes
- New Sounds: No
- New Graphics: No
- New Music: No
- Known bugs: None Known

## Construction

- Editor(s) used: UnrealEd 1, Notepad
- Base: Existing DarkMatch code.

## Installation

Copy the TeamDarkMatch.int file to your Unreal system folder.
Copy the TeamDarkMatch.u file to your Unreal system folder.
