Experience the Wild West in the Unreal Engine. This is a concept of booting up the mod and being able to load the different episodes from the game menu. Why there hasn't been a program like this from Unreal until now is beyond me but now you can finally see what it's like to boot a different experience in Unreal.

Unreal Gold version 226 or 227 is required to run this mod. Extract files for the Unreal Version you have to run this program.
