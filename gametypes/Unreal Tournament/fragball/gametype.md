If you've played the Ut2003 **Bombing Run**, you must play this mod. Probably that's
where the idea for BR came from. And if you don't know it...

**Fragball** is a modification that brings team matches, where two teams compete to put
a ball into a goal. The Impact Hammer has been improved, so it allows you to shot the
ball when you have it. It has a big variety of maps and comes with 4 custom mutators.

It's a very fun mod, although the lack of custom maps can make it a bit repetitive.
Anyway, it's worth a try!

## Installing

Double-click on the UMOD file to automatically install Frag*Ball.

If you downloaded the ZIP file instead, you should unpack the zip file to your Unreal
Tournament installation directory. This is usually:

```
WINDOWS:   C:\UnrealTournament
LINUX:     /usr/local/games/ut
```

## How to play

Frag*Ball is a game type, so it appears in the drop down as another choice besides
Deathmatch, Team Deathmatch, Assault, Domination or Capture the Flag.

Note the the map FB-FragStad requires SGTech.utx which comes with UTBonusPack4. For this
reason the map is not in the default map list.

## Running a server

You should run a server from the UT interface in the normal way, except selecting
Frag*Ball as the game type.

To run a standalone server from a command line, use:

```
ucc "FB-BattleArena?game=FragBall.FragGame"
```

Be careful on UT 436 for Linux from Loki Games, as it creates local copies of many
UT/System files under `$HOME/.loki/ut/System/`. You must either make changes to these
local files or delete these files, so that the files from `/usr/local/games/ut/System/`
are used instead.

## Maps

The Inoxx textures are the same ones that came with the Inoxx Map Pack. They are
included here just in case you don't already have the Inoxx pack. If you don't, go get
it, it has some great maps.

If you installed the Inoxx pack as a umod, when you uninstall it will probably take the
`noxxpack.utx` with it. Restore it from the Frag*Ball UMOD or ZIP file.
