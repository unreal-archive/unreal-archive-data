Initally released 22nd May 2007 (also Unreal's 9th anniversary, strangely enough). Tweaked and
re-released 13 May 2008.

## About

UT Team DarkMatch is the team game version of DarkMatch (DK). For those you who that don't know
what DK is that its a game mode similar to DM except that it takes place on dark maps (TDK
prefix) and that all players are given a searchlight to light up the area.

Note that UT contains no TDK maps but usermade examples exist. For maximum enjoyment it is
recommended that you download TDK-NightOp, which contains a port of the DK-NightOp map from the
original Unreal and the necessary code to unlock the TDK gametype.

Also note that TDK does not mean Team DarkMatch but Tournament DarkMatch, the full name of the
gametype that's hidden away in UT.

## Information

- Editor(s) used: UnrealEd 1 and Notepad
- Base: Existing TDarkMatch code.
- Construction time: 1 hour (really)

## Installation

Extract the UTTeamDarkMatch.int file into your UT's system folder.
Extract the UTTeamDarkMatch.u file into your UT's system folder.

## Usage

On the Practice Session screen there should be a new game type on the list - Tournament Team
DarkMatch. Select it, setup and play!
