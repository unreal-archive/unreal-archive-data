Crystal Element is a third-person fantasy action/adventure game that is a total
conversion for Unreal II.

Here are some of the noteworthy features which make Crystal Element an interesting, fun,
and unique mod for Unreal II.

- Console style Third-Person perspective.
- New Main Character with all new animations and weapons.
- 3 New Levels containing all custom content.
- Completely New enemies and NPCs.
- Story-driven "in game" cinematics.
- RPG Elements with Non-Player Character interaction.

Thanks from all of us for checking Crystal Elements out.

The mod is dead and no longer in development. This beta, released 24 May 2004, is as far
as it got.

## Warning

Installing this software makes permenant modifications to your retail installation of
Unreal II. The game may only be restored to original functionality by reinstalling the
game.

The user also understands that this is Beta version software and has had minimal testing,
and is therefore unfinished and may contain bugs which may result in unpredictable
behavior, gameplay and/or crashes.
