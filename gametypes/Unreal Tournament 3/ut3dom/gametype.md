Domination based Games and Maps for UT3. Domination, Double Domination, Vehicle Domination, and
Vehicular Double Domination game types. All Domination based games support up to 4 team play.
Includes ~20 maps, and it is also fully configurable for all of the games settings via the
WebAdmin.

## Game Types

- **Domination** - Fight for possession of ControlPoints by touching it and your score
  increases until taken by another team.
- **Double Domination** - Battle for control over 2 ControlPoints: A,B Your team must hold both
  ControlPoints for 10 seconds to score.
- **Vehicle Domination** - Using Vehicles, fight for possession of ControlPoints in the map.
- **Vehicular Double Domination** - Using Vehicles, battle for control over two ControlPoints.

## Maps

CDOM-Contrast, DDOM-Aswan, DOM-AKI, DOM-Apodos, DOM-Beesting, DOM-CarnageCathedral, DOM-Cidom,
DOM-Cinder, DOM-Condemned, DOM-Condemned2, DOM-Conduit, DOM-Gearbolt, DOM-Ghardhen, DOM-Lament,
DOM-Pentecost and VDOM-Downtown.

## Requirements

- Unreal Tournament 3 (full version, will not work with the demo)
- Official UT3 Patch 5 (2.1 version) or newer (Not compatible with versions less then 2.0)
- Any version of UT3Dom older then 2.0 must be uninstalled prior to installing a 3.x or newer
  version
- *optional* - WebAdmin support, the WebAdmin mod version 1.4 or newer must be installed

## Changes from version 3 to 3.1

- Fixed scoreboards to display the correct number of teams
- Made UTDomWebAdmin compatible with WebAdmin 1.4 and newer

## Changes from version 2 to 3

- No longer uses the "-mod=UTDom" switch
- Moved VehicleDomination gametype into Domination and VehicularDoubleDom into DoubleDom
- Fixed compatibility with Titan mutator
- Fixed compatibility with the official UT3 patch 2.0, which is now a requirement
- Added the ability for level designers to control what type of ControlPoint will be used when
  using the "Play-In-Editor"
- Fixed translocator trail being the wrong color for the gold team
- Fixed ControlPoint staticmesh sizes
- Fixed Map Voting with the official UT3 patch 2.0
- Added new Kismet event GetMatchSettings that returns the TimeLimit and GoalScore settings for
  the match

## Later versions

Development continued past this release: version 5.0 arrived on 25 December 2010 with a patch
following in February 2012. Those builds were only ever distributed from the mod's own site,
which is gone, and no copy has surfaced since - version 3.1 is the newest that survives.
